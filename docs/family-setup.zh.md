# 给家人（或小团队）搭建 Ourfeed

Ourfeed 不是一个云产品，没有"ourfeed.com"这种东西可以直接注册。你们中的一个人（下面叫"主机"）在自己的电脑上跑起来，其他人都连到这一份实例上。这篇文档就是写给你和不懂技术的家人之间那次"怎么解释"的对话：该告诉他们什么，该发给他们什么。

*(English version: [family-setup.md](family-setup.md))*

## 两种角色

- **主机**：谁的电脑/服务器在跑 `python ourfeed.py`，通常就是搭建这套东西的你。只有别人要用的时候需要在线，手机或者老是休眠的机器不适合当主机。
- **其他人**：只需要一个浏览器，加上下面网络那一步需要装一次 Tailscale。

## 第一步：主机搭好 Ourfeed

按照 [README 的快速开始](../README.md#quick-start) 走一遍。这一步做完，主机自己电脑上打开 `http://localhost:8731` 应该能看到登录页。注册第一个账号，会自动变成管理员。

## 第二步：让大家连上同一个私有网络

这是最容易卡住的一步，值得解释一下为什么需要它。Ourfeed 不挂在公网上，这是特意设计的，不是缺陷：没有人能通过谷歌搜索或者端口扫描碰到你们家的动态流。但这也意味着家人的手机，如果在完全不同的 WiFi 网络下，没法直接输入个地址就连上。你们需要一个跟着设备走的私有网络，这就是 [Tailscale](https://tailscale.com) 的用处。

**为什么推荐 Tailscale**：个人/家庭用免费（免费版最多100台设备），安装大概2分钟，不用配路由器、不用开端口、不用搞固定IP。任何装了它并登录同一个 Tailscale 网络的设备，都能连上这个网络里的其他设备，不管物理上在哪里，家里WiFi、流量、国外的酒店都行。

1. 主机在跑 Ourfeed 的机器上装 Tailscale 并登录（Tailscale账号免费，用谷歌/GitHub/微软账号都能登）。
2. 主机运行 `tailscale ip` 拿到这台机器的 Tailscale IP（长得像 `100.x.x.x`）。Ourfeed 之后就能通过 `http://<这个IP>:8731` 访问。
3. 每个家人在自己的手机/电脑上装 Tailscale app，可以直接加入主机的 Tailscale 网络，或者更好的做法（这样家人不会拿到主机所有设备的访问权限），主机用 [Tailscale 的"共享"功能](https://tailscale.com/kb/1084/sharing) 把跑 Ourfeed 的这一台设备单独共享给每个家人自己的 Tailscale 账号。

## 第三步：主机生成邀请码

用管理员身份登录后，打开 `/admin.html`，点"生成邀请码"。每个码只能用一次，给每个要邀请的人发一个码。

## 第四步：发给家人的话术

直接复制改一改就行，这段是写给完全没听说过"自托管"或"Tailscale"这些词的人看的：

> 嘿，我搭了个只属于我们家的小型"朋友圈/微博"，叫 Ourfeed。家人以外的人都看不到，压根不在公网上。
>
> 连接方法：
> 1. 手机上装个 **Tailscale**（免费，[tailscale.com](https://tailscale.com)），用[谷歌/随便什么方式，看主机那边用的什么]登录。
> 2. 我会把你的账号加进来，这样你就能通过它连到我的电脑，你会收到一个通知，点接受就行。
> 3. 弄完之后，手机浏览器打开这个地址：`http://<tailscale的IP>:8731`
> 4. 点"用邀请码注册"，用这个码：`<邀请码>`，用户名密码随便设。
>
> 这样就好了，收藏一下这个页面或者存到手机主屏幕，之后用起来跟普通app一样。

## 常见问题

- **"提示连不上服务器"**：主机的电脑大概率休眠了，或者 Ourfeed 没在跑。Ourfeed 只有在主机开着机、`python ourfeed.py` 这个进程在跑的时候才能用（或者设成开机常驻服务，见 README 的部署说明）。
- **"Tailscale装了但页面打不开"**：去 Tailscale 管理后台（login.tailscale.com）确认两台设备都显示已连接，并且用的是 Tailscale 的 IP（`100.x.x.x`），不是 `localhost`，也不是主机家里WiFi的普通IP。
- **忘记密码**：没有自助找回，找管理员（跑Ourfeed的那个人）直接去数据库里重置。

## Tailscale 以外的方案

如果家人一直在同一个家庭WiFi下（比如一家人都在家里），根本不需要 Tailscale，直接用主机的局域网IP（`http://192.168.x.x:8731`）就行。只有当有人需要从这个网络外面连进来时，Tailscale 才有意义。如果你熟悉反向代理、域名、TLS证书这些，用 Caddy 或 nginx 配自己的域名把 Ourfeed 挂出去也是个选项，但对着不懂技术的家人第一次搭建的话，Tailscale 需要解释的东西最少。
